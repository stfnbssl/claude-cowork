**OM6 - Statuto epistemologico degli assi strutturali di sviluppo**
===================================================================

+------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| Questo documento chiarisce come gli **assi strutturali** si collocano rispetto a tre rischi epistemologici classici:                                                   |
|                                                                                                                                                                        |
| 1.  essere interpretati come **variabili empiriche non verificabili**                                                                                                  |
|                                                                                                                                                                        |
| 2.  essere percepiti come **metafore filosofiche non scientifiche**                                                                                                    |
|                                                                                                                                                                        |
| 3.  essere scambiati per **una teoria generale dello sviluppo**                                                                                                        |
|                                                                                                                                                                        |
| Deve quindi chiarire:                                                                                                                                                  |
|                                                                                                                                                                        |
| -   **che cosa sono gli assi**                                                                                                                                         |
|                                                                                                                                                                        |
| -   **che cosa non sono**                                                                                                                                              |
|                                                                                                                                                                        |
| -   **come si collegano alla ricerca empirica**                                                                                                                        |
|                                                                                                                                                                        |
| e **mettere definitivamente al sicuro il progetto da una critica tipica dei revisori**, cioè: "gli assi non sono falsificabili", perché qui si chiarisce che gli assi: |
|                                                                                                                                                                        |
| -   non sono ipotesi empiriche                                                                                                                                         |
|                                                                                                                                                                        |
| -   sono **framework interpretativi che generano strumenti empiricamente valutabili**.                                                                                 |
|                                                                                                                                                                        |
| Questo è esattamente lo statuto che hanno molti concetti teorici nelle scienze dello sviluppo.                                                                         |
+------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

Funzione degli assi strutturali nel modello di sviluppo
-------------------------------------------------------

Nel progetto "Sviluppo Bambino", gli assi strutturali costituiscono il principale esito della fase di fondazione filosofico-concettuale.

Essi sono stati introdotti per descrivere lo sviluppo umano non come una sequenza lineare di acquisizioni o competenze, ma come configurazione dinamica di dimensioni strutturali che attraversano l'intero processo evolutivo.

Gli assi non rappresentano fasi cronologiche, stadi di sviluppo o obiettivi normativi. Essi identificano piuttosto **dimensioni fondamentali dell'esperienza di crescita**, che rimangono compresenti e interrelate lungo l'intero arco dello sviluppo.

La loro funzione principale è fornire una **grammatica concettuale dello sviluppo**, capace di rendere intelligibile la complessità dei processi evolutivi senza ridurli a indicatori isolati o a traiettorie prestazionali.

**Distinzione tra strutture interpretative e variabili empiriche**
------------------------------------------------------------------

Dal punto di vista epistemologico, gli assi strutturali non devono essere interpretati come variabili empiriche né come ipotesi sperimentali direttamente verificabili.

Essi appartengono piuttosto al livello delle **strutture interpretative** che orientano l'osservazione dei fenomeni di sviluppo.

Questa distinzione è cruciale. Nelle scienze dello sviluppo esistono numerosi concetti teorici -- come sistema di attaccamento, strutture cognitive o affordances percettive -- che non sono direttamente osservabili ma che svolgono una funzione fondamentale nell'organizzazione dell'osservazione empirica.

Gli assi strutturali svolgono una funzione analoga: non costituiscono oggetti di misurazione, ma dispositivi concettuali che permettono di riconoscere configurazioni di fenomeni e di orientare la costruzione degli strumenti di osservazione.

**Assi strutturali e osservazione dei fenomeni**
------------------------------------------------

La relazione tra assi strutturali ed evidenza empirica non è diretta ma mediata.

Gli assi non generano predizioni sperimentali nel senso proprio delle teorie empiriche. Essi operano piuttosto come **principi organizzatori dell'osservazione**, che rendono possibile individuare dimensioni rilevanti nei fenomeni di sviluppo.

In questo senso, il loro contributo alla ricerca empirica consiste nel:

-   orientare l'attenzione verso configurazioni relazionali e dinamiche spesso trascurate da modelli riduzionisti

-   sostenere la costruzione di strumenti osservativi più sensibili alla complessità dei processi evolutivi

-   fornire un linguaggio comune per la descrizione interdisciplinare delle situazioni di sviluppo.

**Mediazione metodologica tra fondazione concettuale e ricerca empirica**
-------------------------------------------------------------------------

Nel modello metodologico del progetto, la relazione tra assi strutturali ed evidenza empirica avviene attraverso passaggi intermedi espliciti.

Gli assi strutturali orientano la costruzione di:

-   operatori di lettura dei fenomeni

-   strumenti osservativi e dispositivi di analisi delle interazioni

-   formati di intervento e accompagnamento dello sviluppo.

Questi strumenti costituiscono il livello a cui la ricerca empirica può intervenire attraverso studi osservazionali, disegni sperimentali e valutazioni di efficacia.

In questa prospettiva, la verificabilità empirica riguarda gli strumenti e i dispositivi costruiti nel quadro del modello, non direttamente gli assi strutturali in quanto tali.

**Apertura alla revisione e confronto scientifico**
---------------------------------------------------

Il fatto che gli assi strutturali non siano variabili empiriche non implica che essi siano sottratti alla discussione scientifica.

Come ogni costruzione teorica nelle scienze umane, essi restano aperti a:

-   confronto critico con altre tradizioni teoriche

-   revisione alla luce di nuove evidenze empiriche

-   reinterpretazione in contesti disciplinari diversi.

Il loro valore scientifico non deriva dalla possibilità di una verifica sperimentale diretta, ma dalla loro capacità di:

-   organizzare in modo coerente l'osservazione dei fenomeni

-   sostenere la costruzione di strumenti operativi non riduzionisti

-   favorire il dialogo tra discipline diverse nello studio dello sviluppo umano.

**Ruolo degli assi nel sistema complessivo del progetto**
---------------------------------------------------------

All'interno dell'architettura metodologica del progetto, gli assi strutturali costituiscono il livello fondativo che orienta l'intero processo di costruzione degli strumenti e delle pratiche di osservazione.

Il loro statuto epistemologico è quindi distinto da quello delle ipotesi empiriche, ma non separato dalla ricerca scientifica.

Essi operano come **strutture concettuali di riferimento** che rendono possibile una produzione controllata di strumenti e ricerche empiriche coerenti con la natura dinamica e relazionale dello sviluppo umano.
