# Domanda professionale

Trasformazione di un nodo trasversale in domanda utilizzabile nei contesti reali. Le domande professionali non classificano né diagnosticano: rendono leggibili configurazioni evolutive.

## Funzione nella pipeline

Costituiscono il quarto passaggio della pipeline di traducibilità: concetto ontologico → concetto-ponte → nodo trasversale → **domande professionali** → operatore di lettura → famiglie di output → output-tipo vuoto.

È il primo passaggio operativo della traducibilità: il punto in cui il concetto teorico diventa strumento di osservazione per il professionista nella situazione concreta.

## Caratteristiche

Le domande professionali sono formulate in modo da:
- essere interrogabili senza formazione filosofica approfondita;
- evitare la classificazione (non: "è nel range normale?");
- orientare l'osservazione del campo relazionale (sì: "come sta funzionando la regolazione in questo momento?").
