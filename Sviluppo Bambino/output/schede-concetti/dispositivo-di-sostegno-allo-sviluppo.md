# Dispositivo di sostegno allo sviluppo

Strumento operativo che nasce da una Configurazione Evolutiva (CE), agisce sul campo relazionale (non sul bambino direttamente) e modifica condizioni di esperienza. È il prodotto della Fase 3 del progetto.

## Il fatto sorprendente

Osservando casi diversi emerge che dispositivi apparentemente molto diversi condividono la stessa struttura funzionale. Cambiano la superficie e il contesto, non la funzione evolutiva. Esempi:
- dialogic book sharing
- gioco condiviso
- routine narrative
- counseling regolativo
- scaffolding educativo

Tutti agiscono su strutture universali dell'esperienza in sviluppo attraverso le stesse forme fondamentali.

## Proprietà emergente: combinazioni funzionali

Uno stesso intervento reale può appartenere a più tipi universali simultaneamente:

| Dispositivo | Tipi |
|---|---|
| DBS | U2 + U4 |
| Counseling genitoriale | U1 + U2 |
| Setting educativo | U3 + U5 |
| Bilancio pediatrico evolutivo | U1 + U2 + U6 |

## Sequenza generativa

CE → Nodo dominante → Funzione richiesta → Tipo universale (U1–U6) → Strumento locale
