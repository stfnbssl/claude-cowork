# 🔹 1. DOVE SERVONO INPUT

Non tutti gli step richiedono input.
Il metodo funziona perché **pochi punti sono vincolati dall’esterno**, il resto è trasformazione.

## ✔ PUNTI DI INPUT OBBLIGATI

### 🔸 F2 — STEP 2

```text
Scelta del tema (atto / fenomeno)
```

Esempio:

* pointing precoce
* richiesta di aiuto

👉 Questo definisce **l’oggetto ontologico**

---

### 🔸 F3 — STEP 7

```text
Scelta del contesto / ambito
```

Esempio:

* clinico (neuropsviluppo)
* educativo
* interazione spontanea

👉 Questo definisce **il vincolo di realtà**

---

### 🔸 F3 — STEP 10 (parziale ma importante)

```text
Costruzione dei casi di stress test
```

👉 Qui fornisci:

* scenari
* varianti limite
* casi ambigui

Questo è input perché:

```text
la qualità del test dipende da quanto “forzi” il modello
```

---

## 🔹 PUNTI DI INPUT FACOLTATIVI (ma strategici)

### 🔸 F3 — STEP 6 (opzionale)

```text
Scelta del livello di severità del test di non-reversibilità
```

Puoi decidere:

* test debole (solo plausibilità)
* test forte (contro-letture sofisticate)

---

### 🔸 F3 — STEP 8 (raramente)

Solo se vuoi guidare:

```text
livello di specificità del dispositivo finale
```

Ma normalmente:
👉 meglio NON intervenire

---

## 🔹 TUTTO IL RESTO

```text
NON richiede input esterno
```

Perché:

* deve emergere dalla struttura
* se lo guidi troppo → rompi il metodo

I tre step introdotti nell'aggiornamento metodologico (2a, 4b, 6) non richiedono input esterni: lavorano su output già prodotti dalla pipeline e non richiedono decisioni del ricercatore.

---

# 🔹 RIASSUNTO OPERATIVO

```text
INPUT OBBLIGATI:
1. F2-STEP 2 → tema
2. F3-STEP 7 → contesto
3. F3-STEP 10 → casi test

INPUT FACOLTATIVI:
4. STEP 6 → severità test
5. STEP 8 → fine tuning (raro)

STEP SENZA INPUT ESTERNO (automatici):
• F2-STEP 2a → verifica nodi canonici N1-N7 (dopo STEP 2)
• F2-STEP 4b → CE Prototipica grammatica configurazioni (dopo STEP 4)
• F2-STEP 6  → output-tipo vuoto / passaporto del tema (dopo STEP 5 verificato)
```

👉 Questo è un punto forte del tuo metodo:

```text
pochi input, alta generatività
```
